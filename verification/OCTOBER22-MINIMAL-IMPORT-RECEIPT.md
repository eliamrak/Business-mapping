## User-visible repairs

- Upload, acknowledgement and observed/verified date bounds come first. Provider/source configuration, billing analysis, saved history, storage details and calculations are collapsed by default. The desktop tool is constrained to 1040px to leave the artwork visible.
- Existing source-set selections are retained, not automatically reset or enabled. Their legacy editor is under advanced declarations; normal uploads do not begin with an exclusion-checkbox wall.
- Validation, saving, server-acknowledged save, duplicate, later history reload, review and uncertain save are distinct states. No fabricated percentage progress is displayed.
- A network/server failure after submission is an uncertain acknowledgement, not proof that nothing saved. Import, pending-overlap decisions and report confirmation stay locked until a successful history reload. The synthetic transport also tests a committed overlap save whose response fails.
- The new-location backfill no longer navigates away to Rooms after import. Existing staged room suggestions, staged labels and review message are retained.
- Genuine conflict review is outside collapsed tools. Destructive source replacement is an advanced, explicit action, never an automatic winner.

## Persistence and reporting distinction

The existing POST transaction returns saved history after commit. The UI uses that response for acknowledged source counts; a separate GET establishes later reloaded state. Package row counts describe the package, not newly added clinical sessions. Original hashes, rows, package receipts and audit history are retained.

The user-supplied new package was inspected structurally only: its attendance and billing collections contain observed bounds but no `reportCoverage`. Observed first/last appointments cannot prove empty days or report completeness. Existing complete-report evaluation already admits an individually proved report using valid existing provider identities without changing frozen source-set membership. This patch does not certify missing proof. A concise exception asks for the actual complete report dates; fields are not filled from occupied dates.

Parent's read-only live inspection found eight persisted sources versus six previously, with observed dates through October 21 but verified metric coverage through October 7. This is live investigation evidence supplied by the parent, not a synthetic import or a claim that this patch has been deployed. Counts may change legitimately if the owner imports again.

## Numerical scope

Normal overlapping imports retain sources automatically only when their evidence can be reconciled deterministically. Exact repeated billing facts from independent sources are deduplicated in derived local fee/minute summaries and visit matching, while raw row diagnostics and within-source multiplicity remain intact. Existing attendance/non-show and same-day override semantics are preserved. Changed amounts, statuses, ambiguous identities or encounters, contradictory complete-report claims and changed proof are not silently resolved.

No database schema, migration, dependency, production configuration, saved business record, existing source declaration, approval journal, icon, Tidal artwork, PDF export body or mobile artifact is changed.
